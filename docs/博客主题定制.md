# 博客主题定制（sitegen 主题契约）

> sitegen 是 mdtool 自带的静态站点生成器（替代 Hexo 的渲染/生成职责，
> 背景与落地史见 [博客文章管理规划.md](博客文章管理规划.md) §7）。本文是
> **主题层契约的权威定义**：哪些能改、在哪改、怎么改。功能与发布流程见
> [博客工作流.md](博客工作流.md)。

## 1. 分层：引擎固定、主题可换、配置可调

| 层 | 位置 | 定位 |
| --- | --- | --- |
| 引擎 | `mdtool/core/sitegen/`（render/generate 等 .py） | markdown→HTML 语义、URL 语义、页面清单。随 mdtool 走，**不提供覆盖**，改它 = 改 mdtool 源码 |
| 默认主题 | `mdtool/core/sitegen/templates/` + `static/`（包内数据，jacman 视觉） | 新站零配置的兜底外观；mdtool 升级可能微调 |
| 站点主题 | 博客目录 `B/theme/`（可选） | **你的外观**，逐文件覆盖默认主题；属于笔记库内容，mdtool 升级不动它 |
| 站点配置 | `B/site.json` | 标量 knobs（见 §3），手改即生效 |

设计取舍（2026-09-08，阶段 4）：**不做 hexo 式插件制主题/渲染器**。个人工具
为"换 markdown 引擎"引入 entry-point 机制收益不抵复杂度；引擎真正的替换面
是 `build_site(posts, spec, *, assets_src, theme_dir, out_dir)` 这个纯函数
接口——UI 只编排不实现，未来换生成器是函数级替换。主题则走覆盖制：
默认主题保证新站起点与打包 exe 自包含，`theme/` 保证外观不与 mdtool 仓库
耦合（这正是 hexo"主题在站点仓、引擎在 npm"的对应物）。

## 2. 主题目录布局与覆盖规则

```
markdown/blog/            ← B：笔记树下的博客目录（QSettings 记忆）
├── site.json             ← 站点配置（含 theme 键）
├── manifest.json         ← 勾选制发布清单
├── assets/               ← 文章媒体
├── theme/                ← 可选主题；整个目录不存在 = 纯默认主题
│   ├── templates/        ← jinja 模板，逐文件覆盖包内同名
│   │   └── index.html    ← 只放想改的文件，不必整套拷贝
│   └── static/           ← 静态资源，整树合并（同名覆盖）
│       └── css/style.css
└── public-sitegen/       ← 生成产物
```

三条覆盖规则：

1. **模板逐文件回退**：查找顺序 `theme/templates/` → 包内默认
   （jinja ChoiceLoader）。`extends`/`include` 走同一顺序——主题的
   `index.html` extends `base.html` 时，base 落回包内默认，所以单文件
   覆盖成立。
2. **静态整树合并**：先拷包内默认（css/style.css、js/site.js、favicon
   三件、css/pygments.css），再把 `theme/static/` 合并进产物，同名文件
   主题赢。主题连引擎生成的 `pygments.css` 都可以再覆盖（正常路径是改
   site.json 的 `pygments_style` 让引擎重新生成）。
3. **theme 目录名可配**：site.json 的 `"theme"` 键（缺省 `"theme"`），
   强制为 B 内相对路径——盘符/绝对/上跳一律回退默认名，不会指到 B 外。

打包（PyInstaller exe）下同样生效：`theme/` 是笔记库里的用户数据，运行
时直读，与包内 datas 无关。

## 3. site.json 键表

| 键 | 缺省 | 说明 |
| --- | --- | --- |
| `title` | 目录名 | 站点名（header 标题、`<title>`、feed） |
| `url` | 空 | 站点根 URL，无尾斜杠；feed/sitemap/og:url 用，外链判定也依赖它 |
| `author` | 空 | 页脚版权、`<meta name="author">` |
| `language` | `zh-CN` | `<html lang>` |
| `per_page` | `10` | 首页每页篇数 |
| `feed_limit` | `20` | atom.xml 收录篇数 |
| `pygments_style` | `friendly` | Pygments 高亮主题名（构建期生成 css/pygments.css），任意 pygments 内置名 |
| `copy_label` | `复制` | 代码复制按钮文案；**改它必须同时覆盖 `static/js/site.js`**（反馈文案写死在其中，见 §5） |
| `theme` | `theme` | 主题目录名（B 内相对路径） |
| `deploy.repo` / `deploy.branch` | 空 / `main` | 产物仓直推目标；repo 为空时「发布站点」拒绝执行 |

## 4. 模板契约

模板文件名是接口，`build_site` 按固定文件名取模板渲染固定页面清单：

| 模板 | 产出 | 上下文变量 |
| --- | --- | --- |
| `base.html` | 全站骨架（header/footer/head） | `spec`、`mathjax`；blocks：`title`/`head`/`wrapper` |
| `post.html` | `article/<id>.html` | `spec`、`post`、`newer`/`older`（相邻文章，可为 None）、`tag_counts`、`mathjax` |
| `index.html` | 首页 + `/page/<k>/` | `spec`、`posts`（本页切片）、`page_no`、`total_pages`、`tag_counts`、`page_url`、`mathjax` |
| `archive.html` | `/archives/` 与月度归档页 | `spec`、`heading`、`months`、`entries`、`mathjax` |
| `list.html` | `/tags/<n>/` 与 `/categories/<p>/` | `spec`、`heading`、`posts`、`mathjax` |
| `tags.html` | `/tags/` 标签云 | `spec`、`tag_counts`、`mathjax` |
| `_aside_tags.html` | 右侧栏标签组件（被 index/post include） | 宿主页上下文 + `tag_counts` |
| `atom.xml` | feed | `spec`、`posts`（feed_limit 切片）、`updated_iso` |
| `sitemap.xml` | 站点地图 | `spec`、`paths`、`lastmod` |

- **全局函数**（所有模板可用）：`abs_url(path)`（拼站点绝对 URL）、
  `coll_url(kind, name)`（标签/分类页 URL）；`page_url(n)` 仅 index 页。
- **`post` 字段**：`id`、`url_path`、`title`、`date`、`categories`、
  `tags`、`description`、`mathjax`、`toc`（条目含 `level`/`text`/`anchor`/
  `num`）、`html`（**唯一的 `| safe` 放行点**，来自引擎渲染）、`excerpt`、
  以及展示属性 `date_display`、`date_iso`、`categories_display`、
  `category_path`。
- `months` 条目：`label`（"2026 年 05 月"）、`url`、`count`；
  `tag_counts`：`(名字, 篇数)` 列表，按篇数降序。
- **URL 习惯**：站内链接一律 `/` 开头根绝对（预览服务器与 Pages 托管都是
  根路径部署）；列表页文章链接写 `/{{ p.url_path }}`。

## 5. 渲染契约（引擎固定，主题层改不了）

以下语义锚在引擎里，改它们 = 改 mdtool 源码；主题的 CSS 类名、JS 选择器
必须与这里对齐：

- **markdown 方言**：CommonMark + table + strikethrough + raw HTML 透传 +
  linkify。
- **链接改写**：正文 `assets/<x>` 相对链接 → 根绝对 `/assets/<x>`（百分号
  编码交给 markdown-it，单次——自己预编码会双重编码致 CJK 404）；外链加
  `target="_blank" rel="noopener"`；站内绝对路径与锚点不动。
- **标题锚点**：h2–h4 生成页内 anchor id（CJK 保留、页内去重），TOC 取
  同一份数据并带层级编号 `X.` / `X.Y` / `X.Y.Z`。
- **代码块 HTML 形状固定**：
  `figure.codeblock > figcaption.codeblock-bar（span.codeblock-lang + button.code-copy-btn）+ pre > code`。
  灯箱行为锚在 `.post-content img` 选择器上，复制按钮锚在
  `.code-copy-btn` 上——主题改版面可以换类名的**样式**，不能换这些**钩子类**。
- **摘要**：front-matter `description` 优先，否则正文开头约 200 字。
- **URL 语义**（页码清单固定）：`article/<id>.html`、`/`、`/page/<k>/`、
  `/archives/`、`/archives/YYYY/MM/`、`/tags/`、`/tags/<n>/`、
  `/categories/<p>/`、`atom.xml`、`sitemap.xml`。
- **`copy_label` 与 site.js 的耦合**：按钮首态文案由引擎按 site.json 生成，
  但"复制成功"反馈与 1.5s 还原逻辑写死在 `static/js/site.js`（事件委托 +
  文案就地写）。换 `copy_label` 时必须同时用主题的
  `static/js/site.js` 覆盖之。

## 6. 实例

### A. 换主题色/字体（只动 CSS）

把仓库里 `mdtool/core/sitegen/static/style.css` 拷到
`B/theme/static/css/style.css`，改顶部色值即可。注意静态覆盖是**整文件**
替换：拷整份再改，别指望增量合并。

### B. 换首页卡片（只动模板）

`B/theme/templates/index.html`（未覆盖的页面全部落回默认主题）：

```jinja
{% extends "base.html" %}
{% block title %}{{ spec.title }}{% endblock %}
{% block wrapper %}
<div class="site-row">
  <div id="main" class="main-col">
    {% for p in posts %}
    <article class="post-card">
      <h2 class="card-title"><a href="/{{ p.url_path }}">{{ p.title }}</a></h2>
      {% if p.excerpt %}<p class="card-excerpt">{{ p.excerpt }}</p>{% endif %}
      {% if p.date_display %}<time class="card-date">{{ p.date_display }}</time>{% endif %}
    </article>
    {% endfor %}
    {% include "_aside_tags.html" %}
  </div>
</div>
{% endblock %}
```

### C. 换高亮主题

site.json 改 `"pygments_style": "monokai"`，重新生成即可；不满意默认的
CSS 组织时再用 `theme/static/css/pygments.css` 整文件接管。

## 7. 边界

- **hexo 形态不适用**：`theme/` 只在 KB 形态（文章在笔记库）生效；hexo
  源仓的主题归 hexo 自己管（jacman 在 hexo 仓里），过渡期后 hexo 行退役。
- **默认主题的视觉基准**是原版 jacman（对齐过程与骨架参数见规划文档 §7
  "视觉对齐定稿"）——想回到"原汁原味"删掉 `theme/` 重新生成即可。
