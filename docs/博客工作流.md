# 博客撰写与发布工作流

> 博客源：Hexo 7 + jacman 魔改主题（源码仓与产物仓分离，部署目标
> `luiox.github.io`；源码仓名与本地落位路径属个人环境，不写入本公共仓库）。
> 本文是**操作流程的权威定义**；功能设计见 [博客文章管理规划.md](博客文章管理规划.md)，
> mdtool 侧能力对应 B0–B3（识别/脚手架/图片闭环/发布面板）+ 笔记库抽取。

## 1. 角色分工

| 环节 | 谁 | 说明 |
| --- | --- | --- |
| 写作/编辑 | Typora | 专职编辑，mdtool 不做编辑 |
| 文章元数据/列表/草稿过滤 | mdtool 博客页 | front-matter 五列表格，`含草稿` 开关 |
| 插图 | mdtool「导入图片」 | 拷入 `source/assets/`（时间戳命名），链接上剪贴板，Typora 光标粘贴 |
| 校验 | mdtool「校验全库」 | 失效链接 / 散落媒体 / 图床 URL / 无引用 assets |
| 渲染 + permalink | hexo | `generate` 时魔改钩子自动分配数字索引 id |
| 发布 | mdtool「一键发布」 | `hexo generate` + `hexo deploy`（hexo-deployer-git 推到产物仓） |
| 预览 | mdtool「本地预览」 | `hexo server`（新控制台窗口，<http://localhost:4000>） |

## 2. 撰写回路（日常）

**新文章两条路：**

- **A. 直接写**：mdtool 博客页「新建文章…」（读博客仓 `scaffolds/post.md` 模板，
  自动填 title/date/tags）→ Typora 打开写作 → 需要插图时 mdtool「导入图片…」。
- **B. 从笔记库抽取**：笔记库已有成文时，mdtool 博客页「从笔记库导入…」选一篇或多篇
  → 图床 URL 自动改写为 `assets/<名>`、引用的图片从 KB 媒体根拷入 `source/assets/`
  → 落到 `source/_posts/` → Typora 润色成博客语气。

**纪律（URL 身份 = 文件路径，改前必读）：**

1. **已发布文章不改文件名**。permalink 是 `article/<数字id>.html`，id 由
   `passage_index.json` 按文章路径分配——改名 = 换 id = 老 URL 404。mdtool 博客页
   因此不提供文章重命名入口。
2. `passage_index.json` 存**仓库相对路径**（已加固），随仓库提交，换机器不断链。
3. 草稿放 `source/_drafts/`（hexo 不渲染），定稿挪入 `_posts/`；直接在 `_posts`
   起步也可以（同现状）。
4. 图片一律走「导入图片」进 `assets/`，不手放文章旁（避免散落媒体）。

## 3. 发布回路

```
写完 → mdtool「校验全库」（零失效链接）→ 「一键发布」
       = hexo generate（索引钩子自动给新文章分配 id）
       + hexo deploy（hexo-deployer-git 提交 public/ 到 luiox.github.io）
```

- 发布异常/本地改了主题时先「清理缓存」（`hexo clean`）再发布。
- 产物仓提交人为 git 配置身份，失败看 mdtool 日志页的 hexo 输出回显。
- 发布后可开 <https://luiox.github.io> 验证（或本地预览核对样式）。

## 4. 博客仓魔改备忘（mdtool 不碰的部分）

- `generate_passage_index.js`：为 `_posts/*.md` 维护 `{path → id}` 索引，**只增不改**
  （存量 id 永不复用/重排）；`scripts/set_permalink_by_index.js` 的钩子强制
  `article/<id>.html`。索引在 hexo 插件**加载期**同步生成（`before_generate` 仅兜底）：
  保证新文章首次 build 就拿到稳定数字 id——此前索引在文件处理之后才跑，新文章首发
  permalink 会先落到随机串、二次 build 才变数字 id（URL 首发即变的缺陷，2026-08-31 修复）。
- `passage_index.json` 存仓库相对路径（2026-08-31 迁移完成，id 映射逐一核对不变），
  随仓库提交，换机器不断链。
- jacman 主题与 `_config.yml`（含 `permalink: article/:id.html`）维持手工维护，
  mdtool 不接管主题/构建配置。
- `package.json`/`package-lock.json` 被 git 跟踪（虽曾列于 .gitignore，规则已删）；
  发布依赖 `hexo-deployer-git`（2026-08-31 安装，此前 `hexo deploy` 因缺插件不可用）。

## 7. mdtool 设施 ↔ 流程对照
